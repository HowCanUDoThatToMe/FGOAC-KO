# FGO Arcade 한글패치 v2.0.0

Three Colors 대응을 중심으로 설치·실행 호환성을 확대한 정식 메이저 업데이트입니다. 기존 번역을 유지하면서 새 배포본의 모듈·네트워크·방 기능과 함께 사용할 수 있도록 개선했습니다. 전체 번역을 새로 제작하거나 모든 환경을 지원한다는 뜻은 아닙니다.

## 주요 변경

- **Three Colors 기준 지원:** 확인된 내부 게임 버전 11.51의 Three Colors 모듈 구성을 인식하고, 원래 모듈과 네트워크·방 기능을 유지합니다. 기존 update 1.10 / 11.51 계열도 별도로 지원합니다.
- **새 아이템 보존:** 기존 한국어 이름을 병합하면서 Three Colors에 추가된 25개 아이템을 보존합니다. 새 25개의 이름은 원문을 유지합니다.
- **최초 설정 보완:** 덱의 카드 장수 항목이 없거나 비어 있을 때 기존 카드 선택을 보존하며 보완합니다. 이미 정상인 설정은 그대로 둡니다. 최초 계정 저장소는 기존 파일과 복구 대기 자료가 없는 경우에만 준비하며, 기존 계정 내용을 읽거나 덮어쓰지 않습니다. 마스터 계정 생성·선택은 이용자가 플랫폼에서 해야 합니다.
- **호환 검사 유지:** 런처 전체 해시가 달라도 지원되는 실행 구조라면 허용하며, 서버는 한글화 대상 함수의 호환성을 확인합니다. 번역 차분 원본·모듈 조합·자료 손상·실행 중 변경·복구 검사는 유지합니다. 파일만 있으면 무조건 덮어쓰는 방식은 아닙니다.
- **복원과 사용자 변경 보존:** 설치 실패 시 복구하며, 정상 설치 뒤 사용자가 바꾼 덱·계정은 제거 시 이전 상태로 덮어쓰지 않습니다.

마슈 이름판 수정은 포함합니다. 별도 실험한 마슈 마이룸 대화 자막은 포함하지 않습니다. 게임 본체 11.00은 기존의 별도 추가 패치를 사용하세요.

## Three Colors 설치·최초 실행

1. 전체 ZIP `FGOAC-Korean-Offline-v2.0.0-1of2.zip`, `FGOAC-Korean-Offline-v2.0.0-2of2.zip`을 모두 받아 같은 위치에 풉니다. 하나의 `FGOAC-Korean-Offline-v2.0.0` 폴더에 `engine`, `payload`, `Start-KoreanPatch.cmd`가 있어야 합니다. 이전 설치기 폴더에 섞지 마세요.
2. 플랫폼·게임·서버를 종료하고 세이브·개인 설정을 백업합니다. `Start-KoreanPatch.cmd`를 **우클릭 → 관리자 권한으로 실행**한 뒤 **자료 검사**를 실행합니다.
3. `App`과 `Server`가 함께 있는 **게임 최상위 폴더**를 선택하고 **설치 / 업데이트**를 누릅니다. 게임 폴더 이름은 Three Colors일 필요가 없습니다.
4. 설치 후 **Three Colors의 로컬 플랫폼**을 관리자 권한으로 실행합니다. **첫 게임 실행 전에 그래픽 설정(해상도·창 모드 등)을 저장하고, 사용할 마스터 계정을 생성·선택**하세요. 기존 계정이 있으면 그 계정을 선택하며 초기화하지 마세요. 계정 생성 시 플랫폼이 요구하면 서버를 먼저 중지합니다.
5. 게임 언어를 **한국어**로 선택합니다. 방별 설정을 사용하는 경우 그곳의 게임 언어도 확인합니다. 이후 **해당 플랫폼의 정상적인 서버·게임 실행 순서**로 실행합니다. 매번 패치를 재설치할 필요는 없습니다.

계정을 선택하면 실행에 필요한 `DEVICE/aime.txt`가 준비됩니다. 누락 오류가 나면 플랫폼의 마스터 계정 생성·선택 상태부터 확인하세요. 다른 사람의 계정 파일을 복사하거나 카드 번호를 임의로 만들지 마세요.

이번 기준은 **Three Colors 배포본**입니다. Three Colors 이용자에게 예전 `1.0 → 1.02 → 1.10` 업데이트를 추가로 덮어쓰도록 요구하지 않습니다. 기존 상태가 불안하면 새 폴더에 준비한 Three Colors에 설치하세요. 이전 패치 관리 기록을 새 폴더로 통째로 옮기지 마세요.

## 기존 update 1.10 이용자

기존 1.10 / 게임 11.51 환경을 계속 쓴다면 새 설치기의 **설치 / 업데이트**를 실행한 뒤 **한글 게임 실행**을 이용합니다. 자동 서버 시작 경로에서는 플랫폼의 서버 시작을 먼저 누르지 않으며 게임으로 바로 들어갈 수 있습니다. 이 안내는 Three Colors의 플랫폼 실행 절차와 다릅니다.

게임 배포본 자체를 기존 1.10에서 Three Colors로 바꾸는 경우에는 기존 패치를 제거한 뒤 전환하거나 새 Three Colors 폴더에 설치하세요. 서로 다른 계열의 패치 파일·관리 기록을 섞지 마세요. 상태 확인·제거·중단 복구는 설치창에서 실행하며 `.fgoac-korean`을 임의로 지우지 않습니다.
