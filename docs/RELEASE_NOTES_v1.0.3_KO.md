# FGO Arcade 한글패치 v1.0.3

런처·로컬 서버 연결 호환성을 개선한 정식 전체 업데이트입니다. 기존 번역과 마슈 이름판 수정은 유지하며, 별도로 시험한 **마슈 대화 자막 기능은 포함하지 않습니다.**

## 지원 기준

**Cloud23333 1.10 업데이트가 적용된 게임 본체 11.51**이 필요합니다. 중국 업데이트 1.02까지만 적용한 본체는 11.00이므로 지원하지 않습니다. 구형 중국어 런처의 구조를 처리할 수 있다는 설명은 구형 게임·DLL·서버 전체를 지원한다는 뜻이 아닙니다. 필요한 원본과 구성요소 검사는 유지합니다.

## 설치·업데이트와 실행

1. 전체 ZIP 두 개를 모두 받아 같은 새 폴더에 풉니다. 이전 배포 폴더에 섞어 풀지 마세요.
2. 게임·플랫폼·서버를 모두 종료하고 세이브·개인 설정을 백업합니다. 게임 종료 후에도 데이터베이스 서버가 남아 있으면, 게임 폴더의 플랫폼을 관리자 권한으로 실행해 **서버 중지**를 누르고 플랫폼도 종료하세요.
3. `Start-KoreanPatch.cmd`를 **우클릭 → 관리자 권한으로 실행**하고 `App`과 `Server`가 함께 있는 게임 폴더를 선택해 **설치 / 업데이트**를 누릅니다. 기존 이용자도 같은 절차로 업데이트할 수 있습니다.
4. 설치가 끝나면 같은 창의 **한글 게임 실행**으로 실행합니다. 로컬 서버 자동 시작 설정을 사용하는 환경에서는 서버를 준비한 뒤 게임으로 바로 들어가며 플랫폼 창이 따로 뜨지 않을 수 있습니다. 플랫폼의 **서버 시작** 버튼을 먼저 누르지 마세요.

설치 자체는 게임을 자동 실행하지 않습니다. 재설치할 필요 없이 같은 설치창의 **한글 게임 실행**을 이용할 수 있습니다. 플랫폼의 서버 시작 버튼은 이번 관리 실행 경로와 통합되지 않았으므로 위 실행 경로를 기준으로 안내합니다. `The requested operation requires elevation` 오류는 관리자 권한 실행 여부를 확인하세요.

## 개선 내용

- 검토한 다국어·중국어 전용·구형 중국어 런처의 실행 구조를 분석하고, 한국어 연결을 적용하도록 호환 범위를 보완했습니다. 알 수 없는 실행 구조는 변경하지 않고 중단합니다.
- 로컬 연결을 PC의 실제 IP·랜카드 구성과 분리했습니다. PC 주소가 `192.168.x.x`가 아니라는 이유만으로 제한하지 않습니다. PC의 네트워크 설정을 바꿀 필요는 없습니다.
- 설정된 로컬 서비스 포트를 반영하고, 준비 상태와 기존 서버 소유 관계를 확인합니다. 원본 서버 설정 대신 세션별 임시 설정을 사용하며, 기존 계정과 데이터베이스 설정은 유지합니다.
- 임시 서버 실행 스크립트를 쓰기 상태로 열어 둬 발생하던 파일 접근 오류를 수정했습니다. 읽기 잠금과 해시 확인으로 실행 전 변경도 확인합니다.
- 여러 설치 전 호환 문제를 함께 표시하고, 설치·업데이트·제거·복구 및 실행 중 변경 보호를 유지합니다.

## 확인 범위와 제한

테스트 폴더에 일반 설치기로 적용한 뒤 기존 설정·계정 파일 보존과 관리 번역 파일 4,365개를 확인했습니다. 사용자가 **한글 표시·게임 플레이·게임 종료 정상**을 확인했습니다. 구형 중국어 런처는 정적 변환·구문 검사를 수행했으며, 모든 구형 조합을 실제 플레이한 것은 아닙니다.

게임 종료가 서버와 데이터베이스까지 종료됐다는 뜻은 아닙니다. 설치·제거 전에는 서버를 정상 중지하세요. 서버 종료 후 임시 파일 정리는 별도 확인 대상이며, 원격 서버에서의 실제 플레이와 IPv6 전용 원격 연결은 지원 검증이 완료되지 않았습니다. 로컬 접속을 기준으로 사용해 주세요.

변경된 v1.0.3 코드의 VirusTotal 결과는 아직 미확인입니다. 배포 파일의 SHA-256과 이번 검사 범위는 릴리스에 첨부한 `SHA256SUMS.txt`와 `SECURITY_CHECK_v1.0.3.json`을 확인하세요. 과거 버전의 백신 결과를 새 코드의 검사 결과로 표시하지 않습니다.

자체 설치기 소스의 MIT 적용 범위는 `engine/licenses/INSTALLER_LICENSE_SCOPE_KO.md`에 있습니다. 게임·번역·이미지·차분 자료와 외부 구성품의 권리는 별도입니다. AI 도구 **OpenAI Codex**와 오픈소스 **PhotoCraft**를 사용했습니다.

상업적·영리적 수익, 판매·광고 수익, 후원·기부 등 어떤 금전적 이익도 받지 않습니다. 권리자 또는 대리인의 DMCA 등 게시 중단 요청을 받으면 해당 자료를 내리고 배포를 중단합니다.
