# FGO Arcade 한글패치 v1.0.2

정식 전체 업데이트입니다. v1.0.1의 서버 호환성 개선을 유지하고, 런처 호환성 개선과 마슈 이름판 수정을 함께 포함합니다. 별도 마슈 수정 파일을 다시 설치할 필요가 없습니다.

## 설치·업데이트

두 ZIP을 같은 위치에 풀고 `Start-KoreanPatch.cmd`를 실행하세요. 게임·서버·로컬 플랫폼을 모두 종료한 뒤 게임 최상위 폴더를 선택합니다. 기존 이용자도 같은 설치 절차로 업데이트할 수 있습니다. 세부 절차는 `INSTALL_KO.txt`에 있습니다.

한 번 설치한 뒤에는 게임 최상위 폴더의 **FGOLocalPlatform.exe를 우클릭 → 관리자 권한으로 실행**하고, 게임 언어를 **한국어**로 두고 **서버 시작 → 게임 시작**으로 실행합니다. 매번 패치 설치창을 열 필요가 없습니다.

`前端 .NET` / `The requested operation requires elevation` / `[FGO-LAUNCHER:15]` 오류가 나오면 플랫폼을 종료하고 관리자 권한으로 다시 실행하세요. 확인한 플랫폼 실행 파일 자체의 권한 요구이며, 이 오류만으로 .NET 미설치나 패치 손상을 뜻하지 않습니다. Windows 실행 정책 변경은 필요하지 않습니다.

## 변경 내용

- `FGO_Launcher.ps1` 전체가 배포 기준과 같아야 하던 검사를 개선했습니다. 주석·줄바꿈·한글화 연결과 무관한 경로·옵션 변경은 유지하고, 필요한 연결 구문의 구조·개수·순서를 확인합니다. 런처를 실행하지 않고 PowerShell 구문 분석기로 검사합니다.
- 런처의 연결 부분이 없거나 중복되거나 문법이 잘못된 경우에는 파일을 변경하지 않고 원인을 안내합니다. 관리 기록 없이 한글화 코드가 들어간 파일이나 설치 후 직접 수정한 관리 대상 파일은 자동으로 덮어쓰지 않습니다.
- 튜토리얼 등 마슈 이름판 수정 5곳을 전체 설치본에 포함했습니다. 기존 마슈 추가 수정 이용자의 결과가 되돌아가지 않도록 통합 여부를 확인합니다.
- 설정 JSON 오류, 필수 항목 누락, 파일 접근·저장 실패의 안내를 보완했습니다. 오류 원인을 확인하지 않고 Windows 실행 정책 변경을 요구하지 않습니다.
- 원본·패치 자료 검사, 사용자 설정 보존, 실행 중 설치 차단, 백업·제거·중단 복구 검사를 유지합니다.

설치·업데이트·제거·복구 등 자동 검사 41개, 실제 런처 구문 검사 6개, 오류 안내 검사 4개를 통과했습니다. 테스트 폴더의 관리 파일 4,365개와 개인 설정 보존을 확인했으며, 2026-10-28 사용자가 관리자 권한 실행 후 테스트가 정상임을 확인했습니다. 모든 PC나 UI 상태의 검수를 뜻하지 않습니다.

상업적·영리적 수익, 판매·광고 수익, 후원·기부 등 어떤 금전적 이익도 받지 않습니다. 권리자 또는 대리인의 DMCA 통지 등 게시 중단 요청을 받으면 해당 자료를 내리고 배포를 중단합니다.
