# FGO Arcade 한글패치 v1.0.0

전체 자료를 받은 뒤 인터넷 연결 없이 설치하는 Windows 64비트용 한글패치입니다. 두 ZIP을 같은 위치에 풀어 `Start-KoreanPatch.cmd`를 실행하세요. 설치·실행·제거 절차는 `INSTALL_KO.txt`에 있습니다.

## 실행 방식 개선

한 번 설치하면 기존 로컬 플랫폼에서 게임 언어를 [한국어]로 두고 [서버 시작] → [게임 시작]으로 추가 한글 표기까지 적용됩니다. 별도의 ko-fgoac 항목이나 매번 여는 패치 설치창은 필요하지 않습니다. 이전 r002·r003도 새 설치기로 한 번 업데이트하면 연결됩니다. 같은 번역 자료를 사용하는 실행 연결 수정은 번역 이미지 전체를 다시 복사하지 않습니다. 변경한 실행 스크립트는 백업하고, 제거·중단 복구 시 되돌립니다. 플랫폼 또는 서버가 실행 중이라는 이유로 보조 실행 버튼이 차단되던 문제도 수정했습니다.

## 포함 내용

자체 설치기 소스 9개에 MIT License를 적용하고 GitHub의 `installer/`에 공개했습니다. 정확한 대상은 `engine/licenses/INSTALLER_LICENSE_SCOPE_KO.md`, 전문은 `FGOAC-KO-Installer-MIT.txt`에 있습니다. 게임·번역·이미지·차분 자료나 외부 구성품까지 MIT로 허락하는 것은 아닙니다. 프로젝트의 비영리 운영과 MIT 코드의 상업적 재사용 허용은 구분합니다.

- 승인된 한글 텍스트·이미지와 상점·성별 선택 화면 보완.
- 사용자 원본을 검사하고 차분 자료로 별도 한글 리소스를 생성하는 설치기.
- 설치·업데이트·상태 확인·제거·중단 복구·자료 검사·한글 게임 실행.
- Python 실행 환경과 구성품 고지. Python을 따로 설치할 필요가 없습니다.

이전 다운로드형 `FGOAC-Korean-Setup.exe`와 온라인 시작 스크립트는 제외했습니다. 원본 게임 실행 파일·원본 또는 완성 FARC 전체·세이브·개인 설정은 배포하지 않습니다. AI 도구 OpenAI Codex와 오픈소스 PhotoCraft를 사용했습니다.

## 확인 범위

개발판 0.4.0은 사용자가 맵·전투 플레이를 확인했습니다. 일부 부가 UI와 장식용 제목 이미지에는 일본어가 남아 있습니다. 이후 상점·성별 화면 변경과 새 설치 경로의 실제 화면 확인은 이전 플레이 확인과 구분합니다. 최종 설치·복구·백신 검사 결과는 릴리스에 첨부된 기록을 기준으로 확인해 주세요.

`engine/licenses/SECURITY_CHECK_R001_20261025.json`에는 이전 r001의 Defender 결과와 네 파일의 VirusTotal 보고서가 있습니다. `SECURITY_SCOPE_KO.md`에 적용 범위를 설명했습니다. 수정된 설치기 코드에 과거 결과를 적용하지 않습니다. 악성 탐지 0건이나 해시 일치는 안전 보증이 아닙니다.
