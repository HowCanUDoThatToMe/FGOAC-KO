# FGO Arcade 한국어 패치 v1.0.0 — 오프라인 배포 안내 초안

> 공개 전 검토용 · 2026-10-25. 다운로드·최종 검사·권리 고지·봇 사용법을 확정한 뒤 게시할 문안입니다.

FGO Arcade의 텍스트와 이미지 속 글자를 한국어로 옮긴 팬 패치를 준비하고 있습니다. 메뉴와 전투 안내, 카드 이미지, 일부 서버 표시 문구와 한글 글꼴을 함께 보완했습니다. 기존 개발판 0.4.0의 결과와 이후 상점·성별 변경 화면 수정을 v1.0.0 배포 후보에 반영하는 작업입니다.

**게임 원본 파일 없이 패치만 공유합니다.** 게임 본체, 원본 실행 파일, 원본·완성 FARC 전체, 세이브와 개인 설정은 배포 대상이 아닙니다. 설치에는 별도로 이용 권한을 갖춘 호환 게임 환경이 필요합니다.

**어떤 형태의 수익·후원·기부도 받지 않습니다.** 이 프로젝트는 철저히 비상업적·비영리로 운영하며, 판매 수익·광고 수익·유료 서비스 대가·후원금·기부금 등 패치와 관련한 일체의 금전적 이익을 받지 않고 모금도 하지 않습니다.

**이 패치는 AI 도구인 OpenAI Codex를 사용해 제작했습니다.** 번역·코드 작성·자료 통합·검증 보조·문서 작성에 Codex를 활용했으며, 일부 이미지 작업에는 AI 이미지 생성 도구도 사용했습니다. 사용자가 직접 준비한 이미지와 직접 확인한 플레이 결과도 함께 반영했습니다. 모든 문장·이미지·기능을 사람이 전수 검수했다는 뜻은 아니며, AI가 만든 결과에는 오역이나 오류가 남아 있을 수 있습니다.

**[PhotoCraft](https://github.com/storytold/photocraft)** — 이미지 편집·크기 조정·투명도 확인·저장 및 PNG 내보내기에 사용한 오픈소스 도구입니다. 작업 기록에서 v0.15.1 사용을 확인했습니다. ArtCraft Team 및 PhotoCraft contributors의 프로젝트이며, 해당 버전은 [MIT](https://github.com/storytold/photocraft/blob/v0.15.1/LICENSE-MIT) 또는 [Apache-2.0](https://github.com/storytold/photocraft/blob/v0.15.1/LICENSE-APACHE) 라이선스를 선택할 수 있습니다. 여기서는 제작 도구 사용 사실을 밝히며 PhotoCraft 프로그램 자체를 패치에 동봉하지 않습니다.

## 이번 배포의 구성

- 번역 텍스트, 한글 글꼴, 메뉴·전투 안내 이미지와 카드 이미지 보완 결과.
- 0.4.0에서 적용한 일반 이미지 작업 범위 973개와 연결 대상 1,185개. 게임 전체 번역률을 뜻하는 숫자는 아닙니다.
- 사용자가 승인한 개념예장 원본 1,166개의 적용 결과, 별도 서번트 카드 40개의 선 잔여 수정 결과.
- 최근 상점 메뉴 두 곳과 성별 변경 제목·남성 버튼 등 4개 요소, 10개 상태 이미지 보완.
- 전체 자료를 내려받은 뒤 사용하는 오프라인 설치 방식. 설치·업데이트·상태 확인·제거·중단 복구 기능은 최종 묶음 시험 후 안내를 확정합니다.

사용자가 0.4.0으로 실제 맵·전투를 플레이해 진행에 지장이 없음을 확인했습니다. 일부 부가 UI와 장식용 제목 이미지에는 일본어가 남아 있습니다. 이후 추가한 10개 이미지 상태의 실제 화면 및 새 오프라인 설치 경로의 검수는 별도입니다. 전 화면·전 문장 검수 완료나 완전 한글화를 주장하지 않습니다.

## 설치 요약

지원 기준은 Windows 64비트, 제작 시 확인한 Cloud23333 업데이트 1.10 적용 환경(내부 게임 버전 11.51)입니다. 영문 런처 자료가 포함된 기준 환경이므로 같은 버전의 모든 배포본을 보증하지 않으며 원본 파일 검사 결과가 맞아야 합니다.

1. **[공개 전 확인 필요: 최종 다운로드 주소]**에서 1of2·2of2 ZIP을 모두 받습니다.
2. 두 ZIP을 같은 위치에 풀어 하나의 `FGOAC-Korean-Offline-v1.0.0` 폴더로 모읍니다.
3. 게임과 서버를 종료하고 `Start-KoreanPatch.cmd`를 실행합니다.
4. **자료 검사** 후 `App`과 `Server`가 함께 있는 게임 폴더를 선택해 **설치 / 업데이트**를 누릅니다.
5. 완료 후 동봉 안내의 한글 실행 절차를 따릅니다. 설치 과정에서 게임을 자동 실행하지 않습니다.

전체 묶음을 받은 뒤 설치에는 인터넷이 필요하지 않습니다. 빠진 자료 자동 다운로드나 자동 업데이트를 하지 않는 구성입니다. 기존 다운로드형 EXE와 PowerShell 한 줄 설치는 폐기합니다. 로컬 r001 후보의 두 ZIP은 합계 약 4.10GB이며, 최종 파일명·용량·여유 공간·SHA-256과 실행 안내는 공개 전 확정합니다.

## 백신 및 문제 제보

이전 다운로드형 설치 EXE는 2026-10-25에 7/68 탐지가 보고됐으며 원인은 미확정입니다. 이 파일은 새 배포물에서 제외합니다. **새 오프라인 묶음은 별도 검사 전입니다.** 이전의 다른 파일 검사 결과나 타 패치의 오탐 사례를 새 묶음의 안전성 근거로 사용하지 않습니다. 경고가 나오면 실행을 멈추고 판정명과 대상 파일을 확인해 주세요. 백신을 끄거나 폴더 전체를 검사 제외하도록 요구하지 않습니다.

오류·오역·설치 문제는 [디스코드 제보 봇 추가 링크](https://discord.com/oauth2/authorize?client_id=1562153790201663578)를 통해 안내할 예정입니다. **서버 초대 링크가 아니며, 제보 명령·사용 위치·첨부 방법·개인정보 처리 안내는 공개 전 확인 필요**입니다. 패치 버전, 해당 화면·문구, 재현 순서와 오류 메시지를 준비해 주세요. 게임 파일·세이브·계정 정보·개인 설정은 보내지 마세요. 설치기가 자동으로 자료를 전송하지 않으며 답변·수정 일정을 보장하지 않습니다.

## 저작권 및 이용 안내

게임과 관련 명칭·캐릭터·이미지·음악·원문의 권리는 각 권리자에게 있습니다. 본 패치는 개발사·퍼블리셔·권리자와 제휴하거나 승인·후원을 받은 공식 제품이 아닌 비상업적·비영리 팬 프로젝트입니다. 무료 또는 차분 형태의 배포만으로 권리 문제가 자동 해소되지는 않습니다.

자료는 제공된 상태로 제공하며 오류 없음, 모든 환경에서의 작동, 계속되는 지원을 보증하지 않습니다. 설치 전 호환 환경을 확인하고 필요한 데이터를 백업해 주세요. 적용 법령상 허용되는 범위의 책임 제한이며, 법적으로 배제할 수 없는 책임을 없애거나 적법성을 보증하는 문구가 아닙니다. 

**권리자 또는 그 대리인으로부터 DMCA 통지 등 저작권 침해 신고나 게시 중단 요청을 받으면, 해당 자료를 내리고 배포를 중단하겠습니다.** 이 방침은 권리자의 권리를 존중하기 위한 운영 원칙이며, 이용허락이나 적법성·면책을 보증하는 문구가 아닙니다.

원작 제작진, 한국어 제작·검수 참여자, Cloud23333와 FGOAC scooby 기여자, Noto 글꼴 및 Python·Tcl/Tk·Zig·MinGW-w64 기여자에게 감사를 표합니다. 제3자 구성요소의 라이선스와 고지는 각각 유지하며, 이를 게임 자료 전체에 적용하지 않습니다. 상세 설치·지원 범위와 크레딧은 [README 초안](../README.md)에 정리했습니다.
