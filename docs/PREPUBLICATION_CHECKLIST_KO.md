# 일반 배포 전 확인 사항

2026-10-25. 비공개 저장소 준비 문서이며, 전체 패치의 재배포 권한이나 안전성 확인 완료를 뜻하지 않습니다.

## 현재 준비 상태

오프라인 r001 후보는 두 개의 ZIP으로 생성돼 있습니다. 합계 4,101,875,671바이트(약 4.10GB)이며, 두 ZIP을 같은 위치에 풀어 시작 CMD로 설치창을 여는 구성입니다. 기존 다운로드형 설치 EXE와 온라인 PowerShell 시작 스크립트는 제외했습니다.

설치 담당 작업의 기록에서 합성 시험 14개 통과, 동봉 Python을 통한 GUI 생성 시험, 자료 ZIP 8개 검사, 외부 ZIP 전체의 CRC·크기·SHA-256 및 합친 파일 목록 일치 확인을 확인했습니다. 이는 실제 게임 파일에 적용한 시험이나 백신 검사가 아닙니다. 새 오프라인 묶음의 실제 게임 적용·복구·화면 확인과 백신 검사는 아직 남아 있습니다.

이 저장소에는 안내문과 제3자 고지 전문을 먼저 정리했습니다. 패치 ZIP과 게임 파일은 이번 문서 반영에 포함하지 않았습니다. 다운로드 개시나 일반 공개 전환을 뜻하지 않습니다.
