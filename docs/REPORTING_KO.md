# 오류·오역·설치 문제 제보

[디스코드 제보 봇 추가](https://discord.com/oauth2/authorize?client_id=1562153790201663578)

위 링크에서 디스코드에 로그인하고 **내 계정에 추가(Add to My Apps)**를 선택합니다. 별도 서버 가입이나 제작자에게 직접 DM을 보낼 필요는 없습니다. `/안내`로 사용법을 확인하고 `/제보`에서 유형·내용·패치 버전을 입력하세요. `/내제보`로 접수 상태와 답변을 확인합니다. 일반 DM으로 보낸 메시지·사진은 정식 제보로 접수되지 않습니다.

스크린샷은 `/제보`의 `사진1`~`사진3`에 첨부합니다. PNG·JPG·GIF·WebP, 최대 3장, 한 장 8 MiB 및 전체 20 MiB까지입니다. 중복 제보는 삼가 주세요. 스팸 방지를 위한 제출 횟수 제한이 있습니다.

## 제보할 때 준비할 내용

- 패치 버전, Windows 버전, 게임 환경
- 문제 종류: 오역·오타 / 이미지·글자 표시 / 설치·업데이트·제거·복구
- 문제가 발생한 화면·문구와 재현 순서
- 기대한 결과와 실제 결과, 필요한 오류 메시지
- 백신 문제라면 백신 이름·판정명·대상 파일명·SHA-256·검사 시각

위 목록은 권장 제보 내용이며 봇의 실제 입력란 이름이 아닙니다. 화면을 첨부할 때는 계정·카드 번호 등 개인정보를 가려 주세요. 게임 전체·원본 실행 파일·FARC·세이브·개인 설정·비밀번호·토큰은 보내지 마세요. 로그도 내용을 확인하지 않은 채 통째로 올리지 마세요.

현재 패치 설치기의 자동 업로드 기능은 제공하지 않습니다. 별도 디스코드 봇이 제보를 어디로 전달·보관하는지는 추가 확인이 필요합니다. 답변·수정 일정이나 상시 운영을 보장하지 않습니다.

## 안내의 확인 범위

명령·첨부 제한 안내는 운영자가 제공한 사용 사양에 따릅니다. 앱 추가 링크가 디스코드 로그인으로 연결되는 것은 확인했으나 실제 계정 설치·제보 전송을 독립적으로 시험한 것은 아닙니다. 보관 기간·삭제 요청 방법은 봇의 최신 `/안내` 또는 운영자 안내를 확인하세요.
